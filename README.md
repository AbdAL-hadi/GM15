# THETIA — ذاتية

تجربة Frontend عربية مستقلة للعطور، مستوحاة من المرجع المرفق. المشروع محلي، ولا يرسل طلبات شراء أو مدفوعات أو بيانات شخصية.

## التشغيل

يتطلب Node.js 22.12+ أو 24، وnpm. تم التنفيذ باستخدام Node 24.14.1.

```powershell
cd C:\AIhack\GM15
npm install
npm run dev
```

افتح العنوان الذي يطبعه Vite، عادةً `http://127.0.0.1:5173`.

```powershell
npm run typecheck
npm run lint
npm test
npm run build
npm run preview -- --port 4173
```

بعد تشغيل معاينة الإنتاج، يمكن فحص استجابة الروابط والأصول باستخدام:

```powershell
node scripts/verify-build.mjs http://127.0.0.1:4173
```

هذا الفحص يتحقق من HTTP وملفات البناء فقط، ولا يستبدل اختبار المتصفح.

## الصفحات

| الرابط | الوظيفة |
| --- | --- |
| `/` | واجهة افتتاحية، المجموعة، استكشاف النوتات، التنسيق، نبذة |
| `/shop` | البحث بالعربية والإنجليزية، نوع المنتج، العائلة، الترتيب |
| `/product/shams` | الزجاجة ثلاثية الأبعاد، الأحجام، السلة، النوتات |
| `/product/:slug` | صفحات المنتجات الستة؛ الزيوت بصورة SVG محلية |
| `/journey/shams` | المراحل الثلاث وشريط تحكم دون أزمنة غير موثّقة |
| `/layering` | اختيار عطر وزيت وحجم، وإضافة التنسيق المدرج كاملًا |
| `/about` | نبذة، مصادر المحتوى، وحدود النسخة التجريبية |

السلة Drawer من أي صفحة. المفضلة من أيقونة القلب على الكمبيوتر، أو من القائمة على الهاتف. تدعم السلة أحجامًا مختلفة للمنتج نفسه، وتدمج الإضافات المتطابقة، وتحفظ محليًا مع المفضلة. حدود الكمية 1–99. تعطل التخزين لا يمنع الاستخدام في الجلسة.

## تجربة الزجاجة

- اسحب أفقيًا للدوران؛ السحب العمودي مخصص لتمرير الصفحة عبر `touch-action: pan-y`.
- يمكن التركيز على المشهد واستعمال السهمين للدوران وHome لإعادة الزاوية.
- الأزرار تفتح الغطاء وتغلقه، وتجرّب الرشّة، وتستكشف النوتات، وتعيد ضبط الحالة.
- الرش مع غطاء مغلق يفتحه أولًا، ثم يعرض رذاذًا تمثيليًا. يوجد مخزن ثابت من 72 نقطة، يعاد استخدامه دون إنشاء مؤثرات متراكمة.
- لكل نوتة زر ووصف نصي. تبقى النوتات والسلة مستقلتين عن Canvas.
- لاختبار البديل يدويًا: `/product/shams?webgl=off`. يظهر رسم SVG وتنبيه، مع بقاء وظائف المنتج الأخرى.
- `prefers-reduced-motion` يوقف انتقالات CSS ويجعل تحريك الغطاء مباشرًا ويقلل مدة الرذاذ.

## البنية

```text
src/data/          المنتجات، النوتات، المراحل التوضيحية، جدول التنسيق
src/state/         منطق السلة، اعتماد التنسيق، Context والتخزين
src/scene/         مشهد Three.js، المجسّم، الغطاء، البخاخ، الرذاذ
src/components/    القشرة المشتركة، السلة، الحوارات، الرسوم المحلية
src/pages/         الصفحات واختبارات التصيير
src/styles.css    CSS منظّم إلى طبقات ونقاط استجابة
scripts/          تحقق HTTP وأصول نسخة الإنتاج
verification/     نتائج الفحوص المنفّذة
```

لإبدال المجسّم بملف GLB رسمي، استبدل `BottleModel` في `src/scene/BottleScene.tsx`، مع إبقاء عقدة الخصائص للتحكم بالغطاء والبخاخ والدوران. افصل عقد GLB وفق الغطاء والرأس والجسم والسائل والملصق. المجسّم الحالي تقريبي، وليس عبوة رسمية معتمدة.

## البيانات والأصول

جميع الأسعار والتوفر تجريبية. نوتات Shams ومجموعات التنسيق موثّقة من موقع THETIA، كما هو مبين في [ASSETS_AND_SOURCES.md](ASSETS_AND_SOURCES.md). توزيع بداية/قلب/قاعدة موجود بملف منفصل وعليه عبارة «توزيع توضيحي للتجربة، يحتاج اعتماد البراند». لا تتضمن النسخة نسب تركيز أو ثبات أو ادعاءات صحية.

الرسوم SVG والمجسّم من إنشاء المشروع. الخطوط والأيقونات محلية عبر npm، ولا يتطلب التشغيل خدمات أو مفاتيح خارجية. يحتاج أي نشر تجاري إلى اعتماد البراند والمحتوى والأصول والأسعار.

عند النشر على مضيف ثابت، وجّه مسارات التطبيق إلى `index.html`. يتضمن `public/_redirects` قاعدة للمضيفين الذين يدعمون صيغة Netlify؛ Vite dev/preview يدعمان فتح الروابط المباشرة محليًا.

## حدود التحقق

نجحت فحوص الأنواع وLint والاختبارات والبناء. اختبارات التصيير تستخدم React server rendering في Node، وليست اختبارات متصفح. فحص HTTP لا ينفّذ JavaScript.

تعذر اختبار المتصفح: المضيف المباشر غير متاح، ثم أوقف حارس أداة Windows التحكم في Edge لأنه لم يستطع تحديد URL بثقة. لم يتم اختبار المظهر أو اللمس أو WebGL أو Console فعليًا، ولم تُلتقط Screenshots. انظر [MANUAL_QA.md](MANUAL_QA.md) و[REQUIREMENTS_CHECKLIST.md](REQUIREMENTS_CHECKLIST.md).
